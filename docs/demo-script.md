# デモ動画の台本

デモ動画（オンライン会場はプレゼン動画）用の台本。**約 3 分**（現地会場のピッチは 6 分＝デモ・発表 5 分＋質疑 1 分なので、そのままピッチの骨組みにも使える）。

## 守ること（審査対象外にならないために）

- **実機で本当に振って撮る**。センサーの値を開発ツールで書き換えたり、「振ったことにする」ボタンを使ったりしない（「デモ動画の偽装」は審査対象外）
- 撮影には `--release` でビルドしたアプリか、`DEV_TOOLS` を付けずに公開した Web 版を使う（開発用ボタンが出ない）
- まだバックエンドとつながっていない機能（友達のデータ・Gemini など）は「**画面はできていて、接続はこれから**」と言う。動いていないものを動いているように見せない
- 画面に映る名前・写真は、本人の許可があるものか架空のものだけにする

## 準備

- [ ] 公開版 https://protein-kanpai-t071.web.app を iPhone の Safari で開く（開発用ボタンは出ない。実機で振って記録できることは確認済み）。または iPhone にアプリを入れておく（`docs/ios.md`）
- [ ] ホーム画面で「タップして準備」を一度押して、モーションの使用を許可しておく
- [ ] プロフィールのアイコンを自分の写真か好きな画像にしておく
- [ ] 撮影：**画面収録**（iPhone のコントロールセンター → 画面収録）と、**手元を撮るカメラ**（もう 1 台のスマホ）
- [ ] 録音：静かな部屋で、スマホのマイクを口元 20cm くらいに
- [ ] スライドを 3 枚用意する：①課題の数字 ②アーキテクチャ図（`docs/images/architecture.png`）③まとめ

## 台本

アプリはデータが仮のものなので、アプリを起動し直すと最初の状態に戻る。撮り直すときは起動し直す。

## 撮影のコツ

- 振るところは**手元とスマホの画面が両方わかる**ように撮る。審査員に「本当に振っている」と伝わるのがいちばん大事
- 振っても進みにくいときは、手首を使って短く強く振る（強さの基準は `lib/shake/shake_counter.dart` の `threshold`）
- セリフは画面を見ながら別に録音して、あとで合わせてもよい
- 書き出しは 1080p の MP4。Google ドライブに入れたら、ブラウザで再生できるか確認する

## 撮ったあと

# デモ動画の台本（下書き）

デモ動画（オンライン会場はプレゼン動画）用。**実機で本当に振って撮る**。位置やセンサーを開発ツールで書き換えて撮ると「デモ動画の偽装」で審査対象外になる。
開発用ボタン（「振ったことにする」）が出ないビルド（`DEV_TOOLS` なし）で撮影する。

## 準備

- [ ] Firebase Hosting で公開した URL をスマホ 2 台（自分役・友達役）で開き、ログインしておく
- [ ] 2 台がお互いにフォローしている
- [ ] 自分のアイコンを写真に変えておく
- [ ] 画面録画（スマホの画面収録）と、手元を撮るカメラの 2 本を用意する

## 流れ（約 3 分）

| 時間 | 画面 | 話すこと |
|---|---|---|
| 0:00 | タイトル | 「運動、一人だと続かない。だから友達と“乾杯”で続ける」 |
| 0:15 | 課題のスライド | 誰の・どんな課題か（根拠の数字） |
| 0:40 | ホーム | 連続日数と今週のスタンプ。「記録はシェイカーを振るだけ」 |
| 0:55 | ホーム →「タップして準備」→ 手元で振る | シェイカーの中身が混ざっていく。「5 / 8」が進む |
| 1:15 | 友達役のスマホ | 「はなこさんが振っています」が出る |
| 1:25 | 2 人同時に振る | 「〇〇さんと乾杯！」のシート。連続日数とボーナス |
| 1:45 | カレンダー | 乾杯した日が金色のスタンプになる |
| 2:00 | プロフィール | 袋の写真から Gemini でプロテインを登録。今週のふりかえり |
| 2:25 | アーキテクチャ図 | Flutter・Firebase・Cloud Run・Gemini の役割と選んだ理由 |
| 2:45 | まとめ | 「今日の 1 回を、友達と」 |

**注意**：Gemini の機能が当日までに動いていなければ、その部分は「予定」と言って画面だけ見せる。動いていないものを動いているように見せない。
